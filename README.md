## About

All solutions are written in **Python**. I started AoC during my PhD in
Mathematics as a way to practise algorithmic thinking outside research, and
have worked through every edition since.

What I enjoy about AoC is that it rewards careful reading of the problem and
clean modelling more than raw coding speed — many puzzles are really about
finding the right data structure or noticing the trick that turns a hard
problem into an easy one.

## Notes

- Each year has its own folder with one file per day.
- Puzzle inputs are not included (AoC's terms ask participants not to share them).
- Some solutions are tidied and commented; others are more "I just wanted that
  star" — these are working notes, not portfolio code. For polished data
  analysis work, see my [data science portfolio](https://github.com/edg93/data-science-portfolio).
